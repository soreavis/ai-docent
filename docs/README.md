Two of the ten skills aren't courses: `start` picks a course for you and `companion` revises what you've already learned. The other eight teach.

The courses run in any agent that reads the Agent Skills standard. Lesson text uses Claude as its worked platform, so the specific menus and commands in exercises are Claude's. The habits they teach are not.
