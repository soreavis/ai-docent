# Game Mode — only active if the learner turned it on in the wizard

If Game Mode is off, ignore this file entirely and keep every Progress Card clean of it.

If it's on, here's how to keep score — **honestly**. Every point comes from something the learner actually did and logged this session. Never award XP for work not done, never inflate a total, and never hand out a badge they didn't earn. Each session, *recompute* XP from the logged counts rather than trusting a remembered running total — an unearned point is a fabrication, and a craft built on testing what actually works can't fake its own scoreboard.

## XP — earned per real event

- Exercise completed: **+5**
- Lesson cleared: **+10**
- Boss fight passed: **+50** (no hints, first try: **+75**)
- Rewrote a prompt and measurably improved it: **+15**
- Built a reusable template: **+20**
- Ran an A/B test on a prompt: **+15**

Total XP is the sum across the logs — derive it, never guess it.

## Ranks (by total XP)

Drafter (0–49) → Crafter (50–149) → Composer (150–299) → Prompt Architect (300–499) → Prompt Smith (500+).

The bands are what make `next at [n]` on the Progress Card a real number. Compute the rank from the XP you just derived from the logs — never state a rank or a threshold you cannot show the arithmetic for.

Tell them their current rank and how far to the next.

## Streak

Consecutive sessions where they cleared at least one lesson or exercise. Don't break the chain.

## Badges — earned once, for a real milestone

- **First Few-Shot**
- **Format Master** — nailed an exact output spec
- **Chain Builder** — a working multi-step prompt
- **Template Library** — built the reusable library
- **Meta-Prompter** — used a prompt to improve a prompt
- **No-Hint Boss** — cleared a boss with zero hints

Announce one the moment it's earned, and keep a couple of locked ones in view as a target.

Surface all of this at the **Recap** step — one tasteful line, never confetti that cheapens a serious win — and store it in the Game Mode block of the Progress Card so it carries across sessions.
