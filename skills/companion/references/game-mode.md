# Game Mode — only active if the learner turned it on

If Game Mode is off, ignore this file entirely and keep every Progress Card clean of it.

If it's on, here's how to keep score — **honestly**. Every point comes from an item they actually answered in front of you this session. Never award XP for a drill you skipped, never inflate a total, and recompute from the logged counts each session rather than trusting a remembered number — an unearned point is a fabrication, and revision that flatters someone is worse than no revision, because it tells them they know something they don't.

## XP — earned per real event

- Item held: **+5**
- Item held at the top rung and retired: **+20**
- Item missed and then held next time it came up: **+10** (recovery is the point)
- Full drill session completed: **+15**
- Cross-course retro completed: **+25**

A missed item scores nothing. It also costs nothing — the queue is the consequence.

## Ranks (by items retired)

Rusty (0) → Keeping Up (1–9) → Sharp (10–24) → Retained (25–49) → Second Nature (50+).

Tell them the rank and what the next one takes.

## Streak

Consecutive weeks with at least one drill. Never guess at it: if you can't establish the gap since the last session from a card, say the streak is unknown rather than inventing a number.

## Badges — earned once, for a real milestone

- **First Pass** — completed one drill
- **Clean Sweep** — a full session with nothing missed
- **Comeback** — held an item that had been missed twice
- **Wide Net** — items retired from four different courses
- **Nothing Quiet** — no course untouched for more than a month

Announce one the moment it's earned, keep one locked badge in view, and store all of it in the Game Mode line of the card so it survives between sessions.
