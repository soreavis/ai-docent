# Game Mode — only active if the learner turned it on in the wizard

If Game Mode is off, ignore this file entirely and keep every Progress Card clean of it.

If it's on, here's how to keep score — **honestly**. Every point comes from something the learner actually did and logged this session. Never award XP for work not done, never inflate a total, and never hand out a badge they didn't earn. Each session, *recompute* XP from the logged counts rather than trusting a remembered running total — an unearned point is a fabrication, and a course whose whole subject is not trusting remembered state cannot trust its own.

## XP — earned per real event

- Exercise completed: **+5**
- Lesson cleared: **+10**
- Boss fight passed: **+50** (no hints, first try: **+75**)
- Wrote a project artifact that survived a fresh session: **+20**
- Resumed the project cold with nothing but your notes: **+25**
- Recovered a session that went sideways: **+20**
- Logged a drift incident with what would have caught it: **+15**

Total XP is the sum across the logs — derive it, never guess it.

## Ranks (by total XP)

Sprinter (0–49) → Pacer (50–149) → Navigator (150–299) → Marathoner (300–499) → Expedition Lead (500+).

The bands are what make `next at [n]` on the Progress Card a real number. Compute the rank from the XP you just derived from the logs — never state a rank or a threshold you cannot show the arithmetic for.

Tell them their current rank and how far to the next.

## Streak

Consecutive sessions where they cleared at least one lesson or exercise. Don't break the chain.

## Badges — earned once, for a real milestone

- **Cold Resume** — picked the project back up from notes alone
- **Decision Log** — kept one current through a whole level
- **Checkpoint Saver** — rolled back a bad session cleanly
- **Week Two** — carried the project across a real multi-day gap
- **Parked Well** — wrote a parking note someone could restart from
- **Streak Keeper** — a five-session streak

Announce one the moment it's earned, and keep a couple of locked ones in view as a target.

Surface all of this at the **Recap** step — one tasteful line, never confetti that cheapens a serious win — and store it in the Game Mode block of the Progress Card so it carries across sessions.
