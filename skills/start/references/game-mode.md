# Game Mode — only active if the learner turned it on

If Game Mode is off, ignore this file entirely and keep every Program Card clean of it.

If it's on, here's how to keep score — **honestly**. This launcher scores the *program*, not the lessons; each course keeps its own XP inside its own card. Every point here comes from a course the learner actually told you they finished. Never award progress for a course you merely recommended, never inflate a total, and recompute from the completed list each session rather than trusting a remembered number — an unearned point is a fabrication, and this whole family of courses is about knowing what's real.

## XP — earned per real event

- Course started (first session done): **+10**
- Course completed: **+100**
- Track built and confirmed: **+15**
- Returned after a gap of two weeks or more: **+25** (restarting is the hard part)

Total XP is the sum across the completed list — derive it, never guess it.

## Ranks (by courses completed)

Visitor (0) → Enrolled (1) → Regular (2–3) → Scholar (4–5) → Fellow (6–7) → Docent (8).

Tell them their rank and what the next one takes. "Docent" is the full arc; say plainly that most people stop earlier and that stopping is fine.

## Streak

Consecutive weeks in which they finished at least one session in any course. Don't break the chain — but never guess at it. If you don't know, say the streak is unknown rather than resetting it to a number you made up.

## Badges — earned once, for a real milestone

- **First Door** — finished any course
- **Straight Line** — three courses in arc order
- **Own Path** — three courses in an order they chose, with a reason
- **Comeback** — resumed after a month away
- **Full Arc** — all eight

Announce one the moment it's earned, and keep one locked badge in view as a target. Surface all of this in the Game Mode line of the Program Card so it survives between sessions.
